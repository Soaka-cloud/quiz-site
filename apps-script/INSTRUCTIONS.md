# Приёмник ответов: Google Apps Script

Код: `apps-script/Code.gs`. Ничего не нужно устанавливать — всё делается в браузере.

## 1. Создать таблицу

1. Откройте https://sheets.new (или Google Диск → Создать → Таблица).
2. Назовите её, например `Ответы опроса`.
3. Переименуйте первый лист в **`Ответы`** (иначе скрипт создаст его сам).
4. Скопируйте **ID таблицы** из адресной строки — это часть между `/d/` и `/edit`:

```
https://docs.google.com/spreadsheets/d/ВОТ_ЭТОТ_ID/edit
```

## 2. Вставить скрипт

1. В таблице: **Расширения → Apps Script**. Откроется редактор с файлом `Code.gs`.
2. Удалите в нём всё и вставьте содержимое `apps-script/Code.gs` из репозитория.
3. Сохраните (Ctrl+S).

## 3. Положить ID в Script Properties (не в код)

1. В редакторе скрипта: шестерёнка **Настройки проекта** (слева).
2. Раздел **Свойства скрипта** → **Добавить свойство**:
   - Имя: `SHEET_ID`, Значение: ID из шага 1;
   - (необязательно) Имя: `SHEET_NAME`, Значение: `Ответы`.
3. **Сохранить свойства скрипта**.

## 4. Развернуть как Web App

1. Кнопка **Развернуть** (Deploy) → **Новое развёртывание**.
2. Тип: **Веб-приложение**.
3. Параметры:
   - **Описание**: `survey endpoint`;
   - **Запуск от имени**: `Я` (Me);
   - **У кого есть доступ**: **Все** (Anyone). *Без этого браузер получит отказ на POST.*
4. **Развернуть** → авторизовать доступ к скрипту (Google спросит разрешения: «Просмотр и редактирование ваших таблиц») → **Разрешить**.
5. Скопируйте **URL веб-приложения** — он заканчивается на `/exec`:

```
https://script.google.com/macros/s/AAAAAAAAAAAA/exec
```

## 5. Прописать URL во фронте

1. Откройте `config.js` в корне проекта.
2. Впишите URL из шага 4 в поле `endpoint` (этот файл коммитится — URL не секрет, см. README).

```js
window.SURVEY_CONFIG = {
  endpoint: 'https://script.google.com/macros/s/ВАШ_ID/exec',
};
```

## 6. Проверка вручную

1. Запустите сайт: `python -m http.server 8000` в корне проекта.
2. Откройте http://localhost:8000/ — ответьте на все вопросы, нажмите «Отправить».
3. В таблице должна появиться строка: `Timestamp | Survey | <ответы по колонкам>`.
4. Если видите сообщение об ошибке — откройте в Apps Script **Выполнения** (Executions) и посмотрите текст в `console.error`.

## Что важно знать

- **CORS**: Apps Script не умеет отдавать `Access-Control-Allow-Origin` и не обрабатывает preflight `OPTIONS`. Поэтому фронт шлёт `Content-Type: text/plain;charset=utf-8` — для браузера это «простой» запрос без preflight, а скрипт разбирает тело через `JSON.parse`.
- **Ответ всегда 200**: Apps Script возвращает HTTP 200 даже при ошибке — поэтому код кладёт в тело `{ok:false, error:...}`, а фронт проверяет тело.
- **После правки `Code.gs`** нужно **Развернуть → Управление развёртываниями → ✏ → Версия: Новый выпуск → Развернуть**. URL при этом не меняется.
- **Новая колонка в вопросах**: порядок колонок берётся из первого запроса; если состав вопросов изменится, проще создать новый лист (поменять `SHEET_NAME`) или новую таблицу.
- Квоты Apps Script для анкеты несущественны (≈20 тыс. запросов/день).
