# Тесты quiz-site

Два слоя плюс линт-стража.

## Слой 1 — E2E (Playwright, Chromium)

Запуск: `npx playwright test`. Статический сервер поднимает сам Playwright (`webServer` в `playwright.config.js`, порт 8000).

| Тест | Тип | Что проверяет |
|---|---|---|
| E1 | поведенческий | страница открывается, вопросы и прогресс отрендерились |
| E2 | поведенческий | клик по варианту выбирает его, повторный клик по другому снимает прежний |
| E3 | поведенческий | ответы на все вопросы + отправка → экран благодарности |
| E4 | поведенческий | при отправке уходит POST с JSON: `timestamp` + ответы по вопросам |
| E5 | поведенческий | при ошибке сервера благодарности нет, показано сообщение, кнопка снова активна |
| E6 | поведенческий | кнопка заблокирована, пока не отвечены все вопросы |
| E7 | **lint-тест, не поведенческий** | статическая стража: в DOM нет `[style]` и нет тегов `<style>`. Проверяет соблюдение правила «все стили только в style.css», как линтер — поведение пользователя не описывает |
| E8 | поведенческий | кнопка заблокирована на время ожидания ответа (`aria-busy="true"`), после сетевой ошибки снова активна |

Сеть в E4/E5/E7/E8 перехватывается через `page.route()` — реальных запросов к Apps Script из тестов нет.

## Слой 2 — юнит (node --test)

Запуск: `node --test`.

| Тест | Что проверяет |
|---|---|
| U1 | `buildPayload` отдаёт ответы текстом, в порядке вопросов |
| U2 | `timestamp` — ISO-строка из переданного времени |
| U3 | повторный выбор вопроса заменяет ответ, не добавляя второй |
| U4 | `renderQuestion` отдаёт разметку с крючками `survey-question`, `answer-option`, `data-question-id` |
| U5 | `submitUrl` берёт адрес из конфига, иначе бросает ошибку |
| G1–G3 | статическая стража `apps-script/Code.gs`: парсится как JS, нет литерала Sheet ID, есть `doPost`/`JSON.parse`/`appendRow`/`ContentService` (тоже линт-тесты, не поведенческие) |

## Покрытие

`npx c8 node --test` — покрытие `survey.js` по юнит-слою. Ветки ошибок сети и не-JSON ответа юнит-тестами не покрыты: их поведение закрыто E2E-сценариями E5 и E8.
