# Обновление и кэш: чек-лист

GitHub Pages отдаёт статику с `Cache-Control: max-age=600`, поэтому браузер до 10 минут может
показывать **старую** версию сайта, даже если на сервере уже новая. Это не поломка — это кэш.

## Если видишь старый дизайн (шапка «Опрос», кнопка «Отправить»)

1. **Жёсткая перезагрузка**: `Ctrl + Shift + R` (или `Ctrl + F5`) — **на самой странице сайта**.
2. Если не помогло — открой ссылку с параметром, он обходит кэш:
   `https://soaka-cloud.github.io/quiz-site/?v=3`
3. Не помогло и это — очисти кэш для сайта:
   - **Яндекс Браузер**: `Ctrl + Shift + Delete` → «Кэшированные изображения и файлы» → период «Всё время».
   - **Chrome/Edge**: `Настройки → Конфиденциальность → Очистить данные` → «Изображения и файлы в кэше».
4. Открой сайт в режиме инкогнито (`Ctrl + Shift + N` в Яндекс Браузере). Если там новая версия —
   значит проблема только в кэше обычного профиля.

## Почему так вышло

- `index.html`, `style.css`, `app.js` — статические файлы, а Pages кэширует их на 10 минут.
- Страница, открытая **до** публикации, продолжает держать в памяти старые `app.js` и `questions.js`.

## Что сделано, чтобы это не мешало

- В `index.html` добавлены `meta Cache-Control / Pragma` и версионные ссылки: `style.css?v=3`,
  `app.js?v=3`, `config.js?v=3`. Когда меняешь эти файлы, **подними номер** (`?v=4`) — браузеры
  сразу заберут новую версию, минуя кэш.
- Правило для будущих правок: изменил CSS или JS — обнови `?v=N` в `index.html`.

## Десктоп

На широком экране сайт центрируется по вертикали, карточка шире (640 px), отступы больше.
Мобильный вид (узкий экран) не менялся.
