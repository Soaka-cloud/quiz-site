# Как устроена Google-таблица (после перевода и разбивки по блокам)

## Что изменилось

- **Ответы теперь по-русски.** Раньше в таблицу уходили английские коды (`asia`, `restaurant`), теперь —
  русские слова: `азия`, `пицца`, `ресторан`, `дома вдвоём`. Ты сам читаешь таблицу, поэтому кодом-ключом
  сделал русское слово: оно понятно без словаря.
- **Шапка из двух строк.** Первая строка — названия блоков (ДАТЫ, КУХНЯ, ФОРМАТ, СВОИ ВАРИАНТЫ),
  вторая — подписи колонок (Дата 1…4, Кухни, Формат, Комментарий). Обе строки закреплены при прокрутке.
- **Каждый блок — свои колонки, а не одна свалка.** Так видно, что где, и можно ставить фильтры по
  конкретному столбцу.

## Как выглядит таблица

| Колонка | Что там |
|---|---|
| Когда пришло | метка времени ответа (UTC) |
| С кодировкой всё ок | `utf8` или `preserved` — диагностика мохибэйка |
| Клиент | `web` (сайт) или `smoke` (проверка) |
| ДАТЫ → Дата 1…Дата 4 | выбранные даты, каждая в своей ячейке. Не влезло больше четырёх — первые четыре, остальные всё равно видны в сайте |
| КУХНЯ → Кухни | выбранные кухни через запятую: «азия, роллы» |
| ФОРМАТ → Формат | кафе / ресторан / кофейня / дома вдвоём |
| СВОИ ВАРИАНТЫ → Комментарий | свободный текст из поля «Свои варианты», может быть пустым |

## Что нужно сделать один раз

Скрипт изменился, поэтому:

1. Открой таблицу → `Расширения → Apps Script`.
2. Замени содержимое `Code.gs` на текст из `apps-script/Code.gs`.
3. `Deploy → Manage deployments → ✏ → Version: New version → Deploy`.
4. **Создай новый лист под новые данные**: переименуй текущий лист в `Ответы старые`, чтобы скрипт
   создал новый `Ответы` с новой шапкой. Старые строки останутся как есть, новые пойдут в новые колонки —
   так ничего не перемешается.

## Если хочется вернуть английские коды

Все переводы живут в одном файле — `questions.js`. Достаточно в каждом варианте поменять
`value: 'азия'` обратно на `value: 'asia'`; логика и скрипт трогать не надо.

## Про даты

Даты хранятся текстом, а не датой Google-таблицы: люди пишут «5 декабря», «на следующей неделе»,
и превращение в дату исказило бы смысл. Если нужен автоматический календарь — это отдельная задача,
и там придётся ограничить ввод форматом.
