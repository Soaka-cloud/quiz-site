# Метки смоук-строк для удаления

Все строки, которые создали мои скрипты при отладке. Все опознаются по столбцу **Survey** —
там стоят служебные значения `smoke-manual`, `smoke` или `probe`, которых страница не отправляет никогда
(страница шлёт `default`).

**Как чистить:** открыть таблицу → выделить строку целиком → правый клик → `Delete row`.
Удалять снизу вверх, чтобы номера не съезжали.

## Оставить (настоящие данные)

- Строка с **кодами** — контрольный прогон после `Ctrl+F5`: `remote`/`office`/`hybrid`/`undecided`,
  `real_tasks`/`mentor`/`feedback`/`offer`, `lt10`/`10-20`/`20-40`. Это единственная строка, похожая
  на ответ реального посетителя, — её сохранить как эталон.
- Всё, что появится в таблице после удаления от настоящих людей.

## Если сомневаешься

Смотри на столбец **Survey**: `default` бывает у настоящих ответов, но у служебных строк рядом
есть либо `smoke-manual`/`probe`, либо метка времени из списка выше. Совпадение по времени — самый
надёжный признак.
