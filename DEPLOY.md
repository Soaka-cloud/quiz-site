# Деплой quiz-site: чек-лист

Порядок: сначала таблица + скрипт + развёртывание, потом URL в `config.js`, потом публикация фронта.
URL Web App — **не секрет**: он открыт для «Anyone» и его видно в network-панели любого посетителя.

---

## Часть A. Приёмник в Google (выполняет владелец аккаунта)

- [ ] **1. Создать таблицу.** Открыть https://sheets.new. Назвать, например `Ответы опроса`.
- [ ] **2. Скопировать ID таблицы** из адресной строки: между `/d/` и `/edit`.
- [ ] **3. Переименовать первый лист** в `Ответы` (или пропустить — скрипт создаст лист сам).
- [ ] **4. Открыть редактор скрипта:** в таблице `Extensions` → `Apps Script`.
- [ ] **5. Заменить содержимое `Code.gs`** на текст из `apps-script/Code.gs` этого репозитория. Сохранить (Ctrl+S).
- [ ] **6. Script Properties:** шестерёнка `Project Settings` → блок `Script Properties` → `Add script property`:
      - `SHEET_ID` = ID из шага 2;
      - (необязательно) `SHEET_NAME` = `Ответы`.
      → `Save script properties`.
- [ ] **7. Развернуть:** `Deploy` → `New deployment` → тип `Web app`.
      - `Description`: `survey endpoint`;
      - `Execute as`: **Me** (я);
      - `Who has access`: **Anyone**;
      - `Deploy` → пройти экран согласия (`Advanced` → `Go to <проект> (unsafe)` при предупреждении) → `Allow`.
- [ ] **8. Скопировать URL Web app** — он заканчивается на `/exec`. Прислать его в чат.

После этих шагов пришли URL — он уже прописан в `config.js`, я прогоню проверки и сделаю один POST.

## Часть A-alt. Если приёмник уже развёрнут (наш случай)

`Code.gs` изменился (добавлены колонки `encoding` и `client` для диагностики кодировки) — нужно
выпустить новую версию существующего развёртывания:

- [ ] **A1.** Открыть таблицу → `Extensions` → `Apps Script`.
- [ ] **A2.** Вставить актуальный текст `apps-script/Code.gs`. Ctrl+S.
- [ ] **A3.** `Deploy` → `Manage deployments` → карандаш ✏ у текущего развёртывания → `Version`: **New version** → `Deploy`.
- [ ] **A4.** URL не меняется, повторно присылать его не нужно.
- [ ] **A5.** Чтобы увидеть новые колонки в таблице: переименовать текущий лист в `Ответы old` —
      скрипт создаст новый лист `Ответы` со свежей шапкой (иначе шапка остаётся старой, а новые
      значения просто лягут в следующие столбцы без заголовков).

## Часть B. Публикация фронта

- [ ] **9. Создать репозиторий** `quiz-site` на GitHub (можно пустой, без README — история уже есть локально).
- [ ] **10. Settings → Pages:** `Source` = `Deploy from a branch`; `Branch` = `main`, папка `/ (root)`; `Save`.
- [ ] **11. Дождаться сборки** в том же разделе (обычно 1–2 минуты), получить URL вида `https://soaka-cloud.github.io/quiz-site/` и прислать его.

## Если что-то не сработало

- **«Не удалось отправить» на странице** — открыть в Apps Script `Executions` и посмотреть текст ошибки; чаще всего это `SHEET_ID не задан` или доступ развёрнут не «Anyone».
- **Правка `Code.gs` после деплоя** — `Deploy` → `Manage deployments` → ✏ → `Version: New version` → `Deploy`. URL не меняется.
- **404 на странице GitHub Pages** — проверить, что `Source` указывает на `main` и `/ (root)`, а в корне лежит `index.html`.
